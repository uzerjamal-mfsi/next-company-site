# The Company Website

A company site built with Next.js and Contentful as the headless CMS.

## Install

Requirements: Node.js 24 and pnpm.

```bash
pnpm install
```

Fill in your Contentful credentials in `.env.local` (see `.env.example` for the variable names).

## Run locally

```bash
pnpm dev
```

Open <http://localhost:3000>.

## Run with Docker

```bash
docker compose up
```

Open <http://localhost:3000>.
